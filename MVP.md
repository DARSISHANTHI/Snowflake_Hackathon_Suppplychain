MVP Brief: Aerospace Supply Chain Intelligence Platform Objective: Ontology-governed conversational analytics ensuring one consistent answer per metric across all personas (Planning, Procurement, Logistics, Manufacturing, Finance). Architecture: Source Systems → Schema (13 DIM + 13 FACT + 2 META = 28 tables, 36R+ rows) → Ontology Layer (derivation rules, disambiguation matrix) → Semantic Views (9: 5 domain + 3 cross-domain + 1 executive) → Cortex Agent (claude-3-5-sonnet, 10 tools) → Cortex Search (90 docs, Arctic Embed, CDC-backed) → Streamlit UI. Metrics: 24 governed KPIs across 5 domains with RAG thresholds. Key: OTD 95%, Fill Rate 98%, DOI 45d, Yield 97%, Defect <2%. MVP Phases: (1) Foundation: DB + DDL + seed data. (2) Ontology: glossary, metric catalog, semantic views. (3) AI: Cortex Search + Agent. (4) Alerting: derivation views + RAG monitoring. (5) UI: Streamlit + multi-persona validation. Differentiator: Persona-aware disambiguation – ambiguous terms resolve to domain-specific metrics via ontology rules, not guesswork. Stack: Snowflake | Cortex Analyst | Cortex Agents | Cortex Search | Semantic Views | CoCo CLI
